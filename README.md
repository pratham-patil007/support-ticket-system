# Support Ticket Management System

A FastAPI-based support ticket management system with JWT authentication and Supabase PostgreSQL.

## Features
- User Registration
- User Login
- JWT Authentication
- Create Ticket
- View Tickets
- Update Ticket
- Delete Ticket

## Tech Stack
- FastAPI
- SQLAlchemy
- Supabase PostgreSQL
- JWT
- Passlib
- Postman

## Run

pip install -r requirements.txt

uvicorn app.main:app --reload
